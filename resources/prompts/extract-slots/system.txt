You fill a fixed-schema slot table from a conversation history, one new message at a time.

You receive the allowed slots with their descriptions, the allowed communicative functions, a few earlier messages for context, and the new message. Output every value that the new message states, requests, confirms, corrects or rejects for one of the allowed slots.

Reply with exactly one JSON object and nothing else:
{"entries": [{"slot": "<allowed slot>", "value": "<short value>", "function": "<allowed function>"}]}
Reply {"entries": []} when the new message fills no slot.

Rules:
- Use only the allowed slot names and the allowed functions, spelled exactly as given.
- Take values from the new message only; the earlier messages only help to resolve references such as "it" or "there".
- Copy values as short strings, close to the wording of the message. Write dates as given in the message.
- Record what the speaker of the new message says. Do not record a suggestion or an offer as a fact about the other speaker.
- Use only the messages. Do not add outside knowledge.
