# Paper

Manuscript sources.

- LaTeX sources are in `latex/` (target: ESWC 2027 Research Track, Springer LNCS `llncs` v2.24). `latex/main.tex` is the entry point and each section is a file under `latex/sections/`. Run `make` in `latex/` to build `latex/build/main.pdf` (git-ignored), `make clean` to remove intermediate files and `make distclean` to remove `build/`. Without a local TeX installation, run `make tools` once to download tectonic into `$PROJECT_ROOT/.tools/` (git-ignored); `make` then uses it automatically. `make docker` builds in a TeX Live container instead.
- Bibliography: `references.bib` (shared with `docs/research/literature.md`), style `splncs04`.
- Every figure and table is generated by a script under `paper/figures/` from completed run reports listed in `docs/work/experiments/`; never paste numbers by hand.
- Method figures are HTML pages under `figures/html/` (Fig. 1: `overview.html`); each draws its SVG with the shared helpers in `figures/html/figlib.js`. Open `figures/html/index.html` to browse them; its "Drafts" section lists the pages in `figures/draft/` (git-ignored work in progress) without a hard-coded list, either from the HTTP directory listing (`uv run python -m http.server -d paper/figures`, then open `/html/`) or, on `file://`, from a folder picker. On a figure page, "Print to PDF" gives a vector PDF of the artwork alone (use it in LaTeX); "Download SVG" gives the bare SVG for further editing. Move a draft to `figures/html/` when it is final, and point its links at `index.html` and `figlib.js`.
- Each generated figure or table records the run IDs it was built from.
