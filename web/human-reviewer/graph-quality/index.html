Help

Task

The merged file lists the claims of two agent annotators (A and B) for every segment. Decide every row, following docs/research/graph-quality-annotation.md. Context messages (grey) are not annotated.

Accept A / BKeep that agent's version. For a pair that is identical, one button: Accept.
RejectThe claim does not belong in the reference (not a claim, wrong, or a duplicate).
EditCorrect fields (closed values) or the quote, which must occur verbatim in the message.
Add claimA claim both agents missed, under the message that states it.

Highlighted fields differ between A and B. Need review hides pairs that are identical; spot-check a sample of them in All rows.

Finishing a segment

When every row is decided, Mark segment done (optionally with the minutes spent). Changing a decision reopens the segment. Export JSONL writes the done segments as labels-<annotator>.jsonl (claims renumbered c1..cN, one segment_done each); the agents' stances and entity alignments are not part of the merged file.

Files

Import data reads segments.jsonl and the merged JSONL (pick both at once, or one after the other). Decisions are kept at once in this browser. Save draft downloads them as a JSON backup and Load draft reads it back, to continue in another browser. Nothing is uploaded.
