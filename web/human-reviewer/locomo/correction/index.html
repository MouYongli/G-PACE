Help

Task

Each message shows the dialogue text (extracted evidence underlined) and what the writer extracted there. E009 counts change events, so they matter most: a new value, an ending, a supersession, a correction. Change events shows only those items and the proposed missed events.

claimA new claim with the stance (speaker, function, polarity, mode, certainty) that wrote it.
mention of cXA later stance on an earlier claim. Accept or reject; a rejected claim drops its mentions too.
supersessionAn ending (no replacing claim), a change or a correction. Edit the kind, valid end or replacing claim.
Accept / Reject / EditKeep, remove (spurious) or correct subject, predicate, object and valid time.
+ Missed …Add a claim, an ending or a supersession the writer missed at this message. Endings and supersessions name claim IDs (suggestions appear while typing).

Agent proposals

An agent read both conversations and proposed a decision with a one-line reason for every item (blue box) and a few missed events (dashed cards). They are proposals only: Confirm takes one over, or decide otherwise. Only your decisions and confirmations are exported.

Files

Import data reads the bundle JSON (dialogue, items, proposals). Decisions are kept at once in this browser. Export JSONL writes one record per decision as locomo-corrections-<annotator>.jsonl; Import labels reads such a file back (it replaces the decisions of the conversations it names). python -m grace.cli.annotate.locomo_correction apply --corrections FILE turns it into the corrected extraction.
