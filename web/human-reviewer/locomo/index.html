      Help

      Task

      For each question, decide whether it can be expressed in the query fragment. Judge expressibility, not whether a system would answer it correctly.

      in_fragmentExpressible. Add the operations beyond a single claim pattern and any flag.
      open_reasoningCounterfactual, inference or summary.
      date_arithmeticA duration between two events.
      common_senseExactly one piece of world knowledge is missing.
      otherGive the reason: image_only, annotation_error or beyond_fragment.

      Status

      ○ todo · ◐ draft, kept automatically in this browser · ✓ done, confirmed and complete · ⚑ flagged for a second look · ◆ evidence turn of the current question.

      Only questions marked done are counted and exported. Changing a done question returns it to draft until it is confirmed again.

      Data and files
