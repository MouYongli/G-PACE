      Help

      Task

      A rule has labelled each offer turn, the user turn right after a system offer, as accept, reject or none. Read the system's offer and the user's reply and say whether the rule label is right.

      OfferThe system recommends an entity, asks the user to choose, proposes a booking, or names a new entity.
      acceptThe user takes the offer up, in words (explicit) or by going on with it (implicit).
      rejectThe user turns the offer down, or asks for something that does not fit it.
      noneThe reply neither takes the offer up nor turns it down.
      correctThe rule label matches the reply. When the user declines part of an offer, an accept label is incorrect.
      incorrectIt does not. Say why in the note.
